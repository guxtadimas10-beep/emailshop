# Email Shop 📧

Uma plataforma moderna de **email temporário com domínio .shop** que permite criar contas em serviços sem usar seu email pessoal.

## 🎯 Funcionalidades

✅ **Gerar Emails Temporários** - Crie emails descartáveis com domínio @emailshop.shop  
✅ **Receber Códigos de Verificação** - Simule recebimento de emails com códigos de Netflix, Google, Amazon, etc.  
✅ **Local Storage** - Seus emails e tarefas são salvos localmente no navegador  
✅ **Lista de Tarefas Integrada** - Gerencie suas tarefas enquanto usa o email temporário  
✅ **Design Responsivo** - Funciona perfeitamente em mobile, tablet e desktop  
✅ **Interface Intuitiva** - Simples e fácil de usar  

## 🚀 Como Usar

1. **Gere um Email**
   - Digite um nome para seu email
   - Clique em "Gerar Email"
   - O email será criado com formato: `seuEmail@emailshop.shop`

2. **Use em Serviços**
   - Copie o email gerado
   - Registre-se em serviços como Netflix, Gmail, Amazon, etc.
   - Os códigos de verificação aparecerão na caixa de entrada

3. **Gerencie Tarefas**
   - Adicione tarefas na seção "Minhas Tarefas"
   - Marque como concluídas
   - Todas as tarefas são salvas automaticamente

## 💾 Armazenamento Local

- Todos os dados são armazenados no **Local Storage** do seu navegador
- Nenhuma informação é enviada para servidores
- Seus emails e tarefas persitem entre sessões
